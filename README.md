# PropertyRecords

An iPhone app for repairs, renewals, and property records stored on the device.

## Installation

```sh
git clone https://github.com/P4suta/assets-management.git
cd assets-management
mise install
mise x -- just generate
```

## Usage

```text
Open PropertyRecords.xcodeproj in Xcode.
Run the PropertyRecords scheme on an iPhone simulator.
Add a building and its first room from Properties.
```
